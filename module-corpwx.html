💬 企业微信集成

企微登录 · 消息推送 · 同步通讯录 · 微信公众号

1. 集成总览

系统深度集成企业微信（WeCom）能力，同时支持微信公众号消息：

功能说明代码位置
企微扫码登录 用户通过企业微信扫码直接登录系统 com.xzy.common.corpwx + CorpWxController
企微消息推送 检测进度通知、审核通知等通过企微应用消息推送 ICorpWeChatService / SysCorpWxMessageService
企微消息记录 记录所有已发送的企微消息，支持查看回执 SysCorpWxRecordService
微信公众号 接收微信用户消息，提供证书查询等服务 WxController

2. 企业微信扫码登录流程

前端：用户点击"企微登录" → 打开企微二维码页 后台：CorpWxController 处理 OAuth2 回调 1. 获取 code 2. 通过企微 API 换取 userId 3. 根据 userId 查找/创建本地用户 4. 生成 JWT token 5. 重定向到前端首页（携带 token） 调用链路: GET /corp/wx/login → 跳转企微授权页 GET /corp/wx/callback → OAuth2 回调处理 → userService.uuidLogin() → 生成 token

3. 消息推送

消息推送服务: ICorpWeChatService 实现: CorpWeChatServiceImpl 推送场景: 1. 委托单审核通知 → 通知业务员 2. 证书审核通知 → 通知编制人 3. 任务分配通知 → 通知检测员 4. 样品签收通知 → 通知送检人 数据表: sys_corp_wx_message → 消息内容/接收人/状态 sys_corp_wx_record → 发送记录/回执状态

4. 配置说明

企业微信相关配置在 application-dev.yml（服务器）或 application-local.yml（本地开发，已 .gitignore）中。

配置项说明获取方式
workWechat.corpId企业 ID企微管理后台「我的企业」→ 企业信息
workWechat.appAgentId应用 AgentId企微管理后台「应用管理」→ 自建应用
workWechat.appSecret应用 Secret企微管理后台「应用管理」→ 自建应用 → 查看 Secret
wechat.appid微信公众号 AppID微信公众号后台「开发」→ 基本配置
wechat.secret微信公众号 Secret微信公众号后台「开发」→ 基本配置
⚠️ 注意：
• 企业微信 Secret 和公众号 Secret 不应以明文形式提交到 git 仓库（当前 dev 和 local 配置中存在明文，后续应迁移到环境变量或密钥管理服务）
• 本地开发使用自己的测试企微应用，不要用线上应用的 Secret
• 回调地址必须与企微管理后台配置的 redirect-url 一致
# application-local.yml 中的真实配置示例（值已脱敏） workWechat: corpId: wwcd5e975979ae9944 # 企业 ID：可从企微后台获取 appAgentId: 1000024 # 应用 AgentId appSecret: xxxxxx # 找负责人获取，不写在公开文档中 redirect-url: https://lims.xiziyi.cn/corp/wx/callback
