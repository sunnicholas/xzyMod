📊 系统监控

操作日志 / 登录日志 / 在线用户 / 定时任务 / 服务监控 / 缓存监控 / Druid 监控

1. 模块综述

系统监控模块提供完整的运维监控能力，涵盖操作审计、登录审计、在线用户管理、定时任务调度、服务器健康检查、缓存管理以及数据库连接池监控。

📌 前端页面：src/views/monitor/（7 个子模块）
📌 后端路由前缀：/monitor/**
📌 核心依赖：Quartz（定时任务）+ OSHI（系统监控）

2. 功能清单

功能前端页面后端 Controller说明
操作日志 views/monitor/operlog/ SysOperlogController 记录所有 @Log 注解的操作，支持导出和清理
登录日志 views/monitor/logininfor/ SysLogininforController 记录所有登录成功/失败日志
在线用户 views/monitor/online/ SysUserOnlineController 查看在线用户，支持强制下线
定时任务 views/monitor/job/ SysJobController Quartz 任务 CRUD、触发、暂停、恢复
调度日志 views/monitor/job/log/ SysJobLogController 每次任务执行的日志记录
服务监控 views/monitor/server/ ServerController CPU/内存/磁盘/JVM 信息（OSHI）
缓存监控 views/monitor/cache/ CacheController Redis 缓存信息查询/清理
Druid 监控 views/monitor/druid/ 内置 Servlet 数据库连接池监控页面
🚫 Druid 监控安全：Druid 监控页面 /xzy-api/druid/ 登录密码在 application-druid.yml 中配置（本地默认 ruoyi/123456），线上环境必须修改密码，或通过防火墙限制内网访问。
不要将线上 Druid 监控页暴露到公网。

3. 操作日志（重点）

通过 @Log 注解实现操作日志的 AOP 自动记录：

// Controller 层用法 @Log(title = "委托管理", businessType = BusinessType.INSERT) @PostMapping("/measure/msEntrustTask") public AjaxResult add(@RequestBody MsEntrustTask entity) { ... } // 会自动记录：操作人、IP、操作方法、耗时、请求参数、返回结果 // 存储在: sys_oper_log 表
