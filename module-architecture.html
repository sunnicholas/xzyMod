关键理解：
• xzy-admin 是唯一启动模块，包含 LimsApplication.java 和全部 99 个 Controller
• 业务模块（measure/crm/basics 等）只有 Domain/Mapper/Service，没有 Controller，所有 API 入口在 xzy-admin
• xzy-common 是最底层依赖，所有模块都依赖它
• xzy-framework 是运行框架（安全、AOP、配置），仅 xzy-admin 直接依赖

5. 🚫 禁区清单（修改前必须确认）

🚫 禁区 1：xzy-framework/config/SecurityConfig.java
不要修改：白名单路径、密码编码器（BCryptPasswordEncoder）、JWT 过滤器链。
后果：改了白名单可能导致登录页都打不开；改了密码编码器会导致所有用户密码失效。
🚫 禁区 2：application-druid.yml 的数据库连接
不要修改：spring.datasource.druid.master.url（除非改数据库地址）。
不要修改：spring.datasource.druid.master.password 为明文写在 git 里的线上密码。
线上密码通过私有渠道传递，application-local.yml 已加入 .gitignore。
🚫 禁区 3：XiziYiConfig.java 的路径方法
不要修改：getProfile() 返回路径（由 yml 配置）。
不要新增/删除子路径方法，除非同步修改 CommonController 中的上传接口。
不要硬编码路径字符串，必须通过 XiziYiConfig 的方法获取。
🚫 禁区 4：mybatis-plus 配置中的 mapper-locations
classpath*:mapper/**/*Mapper.xml — 不要修改这个扫描路径。
XML 文件命名必须严格按 XXXMapper.xml 格式，否则不会被加载。
🚫 禁区 5：Tomcat 线程池配置
server.tomcat.threads.max: 800 — 不要随意改大。
当前值已贴近服务器资源上限，改大可能导致 OOM 或 CPU 耗尽。
⚠️ 其他需注意的配置：
• token.secret 在 yml 中为明文占位符，线上环境应使用更强的密钥
• swagger.enabled 生产环境应设为 false，防止 API 泄露
• xss.enabled: true 不要关闭，除非明确知道后果
• referer.enabled: false 防盗链当前关闭，如需打开需统一配置 allowed-domains
