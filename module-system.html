⚙️ 系统管理

xzy-system 模块：用户/角色/菜单/部门/字典/配置/通知/公司/企微

1. 模块综述

系统管理模块（xzy-system）基于 RuoYi 3.8.9 系统管理能力扩展，覆盖标准 RBAC 权限管理、数据字典、参数配置、通知公告、操作日志等基础设施功能，同时扩展了公司信息管理、企业微信消息管理等业务配套功能。

📌 代码模块：xzy-system
📌 Controller 路径：xzy-admin/.../web/controller/system/（约 16 个 Controller）
📌 前端页面：src/views/system/（11 个子模块）

3. RBAC 权限模型

用户 ──┬── 岗位 (sys_post) ├── 部门 (sys_dept) └── 角色 (sys_role) ── 菜单 (sys_menu) └── 权限标识 (perms) 如: measure:msEntrustTask:list system:user:edit crm:crmCustomer:add 权限判断：@PreAuthorize("@ss.hasPermi('xxx:xxx:xxx')") 按钮级： v-hasPermi="['xxx:xxx:xxx']"

4. 登录流程

POST /login → SysLoginController.ajaxLogin() 1. 验证码校验 (CaptchaConfig/Kaptcha) 2. 用户密码校验 (Spring Security AuthenticationManager) 3. 生成 Token (TokenService.createToken()) 4. 返回 token / 用户信息 / 权限列表 GET /getInfo → 获取用户信息 + 角色 + 权限 GET /getRouters → 动态路由（前端根据路由生成菜单） 登录支持： - 账号密码登录 - 企业微信扫码登录 - 微信扫码登录 (uuidLogin)

5. 扩展：公司信息管理

公司管理（sys_company）是系统管理模块的扩展，管理检测机构自身的基础信息，包括公司名称、地址、联系方式、资质信息等。在证书/报告中作为出具机构信息展现。
