⚙️ 质量管理

质量模块(xzy-quality)：技术依据、标准物质、测量标准、设备库

1. 模块综述

质量管理模块（xzy-quality）覆盖实验室质量管理体系的基础数据管理，包括技术依据（检定规程/校准规范）、标准物质、测量标准、仪器设备库。这些数据在检测任务中作为技术支撑信息引用。

📌 代码模块：xzy-quality（含 xzy-measure 中的设备/标准相关服务）
📌 涉及后端 Controller： QuaTechnicalBasisController、QuaTechnicalItemController、MsMeasureStandardController、MsStandardMatterController、MsDeviceLibraryController、MsDeviceExamineController、MsDeviceTraceSourceController
📌 前端页面：views/quality/（4 子模块）

3. 核心数据表

表名说明关键字段
qua_technical_basis技术依据（检定规程/校准规范）id, basis_name, basis_code, dept_id, status
qua_technical_item技术项目明细（检测项/校准项）id, basis_id, item_name, technical_requirement
ms_standard_matter标准物质管理（有证/无证）id, matter_name, grade, purity, due_date
ms_measure_standard测量标准（计量标准器）id, standard_name, measure_range, accuracy
ms_device_library仪器设备库（检测用设备）id, device_name, device_model, manage_no
ms_device_trace_source设备溯源记录（量值传递）id, device_id, trace_date, result

技术依据查询 SQL

-- 技术依据列表查询 SELECT tb.*, dept.dept_name FROM qua_technical_basis tb LEFT JOIN sys_dept dept ON tb.dept_id = dept.dept_id WHERE tb.del_flag = '0' ORDER BY tb.create_time DESC
